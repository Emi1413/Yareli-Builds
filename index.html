Yareli Builds

Loyal Evade Guardian

This the most basic Yareli build i have and the one i use the most. This build is a very good all rounder providing VERY good survivability, decent damage and a somewhat decent range for the forth ability.

There is nothing crazy really just some basic mods like:

  • Arcane Energize - Archon Flow - Equilibrium for Energy sustain
  • Summoner's Wrath - Power Drift - Blinding Rage - Archon intensify - Surging Blades for Strenght for Strenght and damage
  • Loyal Merulina - Augur Accord - Arcane Aegis for survivability
  • Finally Augur reach as a flexible slot for whatever you need or prefer (in this case: Range)

We also have Koumei's subsume for an added layer of survivability on top of what we already have for a chance to ignore incoming damage and getting a heal instead, activating archon intensify.

Loyal Merulina as you probably already know makes so we summon Merulina as a minion instead of as a mount making movement a lot easier while allowing us to subsume our frist ability (because Merulina shoots bubbles that work exactly like our 1) while at the same time allowing us to run "Summoner's Wrath" to buff Merulina's damage. Then we have Aegis that help us keep our shields up, and, that's pretty much it, a very simple and easy build that we can use for pretty much any mission type.

This build is built around Cyte's "Evade" subsume, it makes so we can go invisible every 60 or so seconds for an x amount of time, but, we can extend this by getting headshot kills. As you probably guessed we are building for Duration rather than Strenght because "Evade" scales with Duration, extending the initial duration of this ability.

This build uses the last one as a base so we use similar mods only replacing some Strenght mods for Duration mods and replacing Aegis with Arcane Crepuscular for a little Strenght boost when invis.

As you can see we are using "Loyal Merulina" here too, but, you can use "Guardian Merulina" or another random mod if you want to, this is just quality of life.

For the last build we have a Guardian or a "weapon platform build". Here we use "Merulina Guardian" instead of "Loyal Merulina" because Guardian buff Merulina and our secondary giving it more fire rate, reloading speed and healing merulina with each kill. As you can see this build is almost identical to the frist one only replacing Loyal with Guardian and Aegis with Velocity (this arcane buffs our secondary stacking with Guardian's buffs).

To make this build even stronger we need to subsume our 4 ability with Sevagoths's Gloom making Merulina nearly unkillable as long as we are getting kills of course.

The weapons i use and some builds for them:

  • Latron Prime incarnon
  • Kompressa Prime
  • Coda Caustacyst
  • Furis incarnon
